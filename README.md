# Credit Intelligence Engine v6

Локальная интерактивная платформа кредитной аналитики: EDA → кредитный скоринг → Early Warning → предварительный Next Best Offer → мониторинг качества.

**Источники:** только внутренние события в предоставленных CSV (кредиты, график, транзакции погашений, ежемесячные финансовые движения). Нет обращений к кредитным бюро, базам внешних долгов и сервисам проверки самозапрета. Данные набора демонстрационные, сценарно сгенерированные, не содержат настоящих заёмщиков. При реальной выдаче обязательные регуляторные проверки выполняются в **отдельном существующем кредитном процессе**; этот проект не одобряет и не выдаёт кредиты.

## Быстрый запуск

1. Python 3.11+ и распакованный архив проекта.
2. Windows: `run_windows.bat`. Linux/macOS: `python -m pip install -r requirements.txt && python app.py`.
3. Открыть `http://127.0.0.1:7860`.
4. При необходимости пересчитать данные: `python -m scripts.refresh_project`, модельный паспорт: `python -m scripts.build_model_card`.

## Вкладки интерфейса

1. **Данные** — CSV, включая обязательства, платёжные события, снимки и сверку статусов.
2. **EDA** — риск по сегментам, продуктам и географии (география не используется в скоринге или лимитах).
3. **Градиентный спуск** — ручная скорость обучения, число эпох, регуляризация и ход LogLoss.
4. **θ-лаборатория** — ручная настройка весов и шагов оптимизации.
5. **Сравнение ML** — Logistic Regression, Random Forest, CatBoost, независимый тест.
6. **Risk Dashboard** — портфель, оценка рисков 30/60/90 дней, процентный доход PR, рисковые кредиты.
7. **Decision Engine** — сравнение 4 вариантов на клиента, риск PD12, внутренний ПДН, продукт, сумма, ставка, эффект маркетинга, экспорт `CustomerID`.
8. **Model Monitoring** — OOT, калибровка, ablation, PSI, vintage и roll rates.
9. **Анализ отдельного офера** — 4 предложения одного клиента и причины отбора.

## Разграничение метрик

- `PD12`: вероятность достижения DPD 30+ **хотя бы раз за 12 месяцев после выдачи** в модели нового кредита. Не регуляторный дефолт и не ECL.
- `EW_PD30_30D/60D/90D`: новые события DPD30+ за короткий горизонт для **действующих кредитов с текущим DPD <30**. Отдельная обученная модель.
- `InternalDTI`: `(ежемесячные платежи по текущим кредитам в рассматриваемом банке + новый платёж) / среднемесячный доход`. Внешние долги не известны; не считать показателем полной ПДН клиента.
- `PR`: **процентный доход**, не чистая прибыль, на приближённых остатках.
- `ExpectedLoss`: учебный стресс-прокси `P(DPD30+) × EAD × scenario-LGD`, **не IFRS 9 ECL**.
- `P(Accept)`: пока заданный вручную сценарный коэффициент; нет истории кампаний для обучения модели.
- `EV/contact = P(Accept) × (проценты + доход по рассрочке - кредитный риск - фондирование - обслуживание) - стоимость контакта`.

## Что улучшено по сравнению с v5

- Отдельные таблицы `repayment_obligations.csv` и `repayment_transactions.csv`; возможны частичные платежи.
- Проверка статуса кредита с учётом непогашенной суммы, а не только даты окончания.
- `early_warning_snapshots.csv`: 351 263 наблюдения по кредитам с датами оценок 2023–2026, с расчётом точных горизонтов Target.
- ML Early Warning обучен отдельно на 30, 60 и 90 дней; калиброван и проверен по времени.
- OOT и calibration report для кредитного скоринга PD12, контроль PSI, ablation, миграции DPD, vintage.
- Decision Engine оценивает четыре предложения на клиента и оставляет лучшее в пределах риск-ограничений.
- Изолирован внутренний ПДН, нет внешних API, не имитируются «проверки бюро» или «одобрение».
- Сценарная персональная скидка: **при отсутствии доказанной реакции клиентов на цену её нельзя считать автоматически прибыльной**.
- Экспорт `recommended_customers_v6.csv` отмечает `PRE_OFFER_REVIEW`, `UNKNOWN_NOT_QUERIED`, `NOT_CHECKED_PREOFFER`, `UNKNOWN_REVIEW_REQUIRED`.
- Подготовлена схема `internal_marketing_events.csv`; Propensity не обучается без событий и исходов кампаний.
- Версионирование результатов: `reports/model_registry_v6.json`.

## Структура проекта

```text
app.py                      # 9 вкладок Gradio
src/ml_core.py              # лаборатория градиентного спуска и базовые ML-модели
src/early_warning.py        # отдельные 30/60/90-дневные модели, контроль качества
src/decision_engine_v6.py   # Risk Scoring, 4 офера, экономика контакта, портфель
src/propensity.py           # подключаемый модуль внутренних маркетинговых исходов
src/decision_engine.py      # legacy v5 helpers (аннуитет, амортизация, сценарные классы)
scripts/build_v6_data.py    # нормализация погашений и PIT снимки
scripts/refresh_project.py  # offline пересчёт данных и отчётов
scripts/build_model_card.py # паспорт моделей/данных
reports/                   # проверочные метрики и выгрузки
notebooks/                 # учебные EDA и ML эксперименты
```

Исторические диаграммы качества показывают **результат на демонстрационных данных с заданными поведенческими зависимостями**, не подтверждают применимость к реальным клиентам. Для промышленной эксплуатации потребуется подтверждение данных, согласий, ограничений продукта и итоговое решение в основном кредитном процессе.

Подробности: `docs/ARCHITECTURE.md`, `docs/DECISION_ENGINE.md`, `INTERFACE_GUIDE.md`.
